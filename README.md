# Course work HH API
## Есть классы Vacancies, JsonFile, HH_API, HH_API_ABC, FileManager.
###  FileManager и HH_API - абстрактные классы, которые содержат методы, которые реализованы в наследуемых классах
### Класс Vacancies содержит 4 атрибута
### В JSON-файл сохраняются данные, соответствующие атрибутам класса вакансий, с данными в виде списка словарей.
### В пакете tests содержатся тесты ко всем функциональностям
